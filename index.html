What this tool does

Screen for timing differences; do not treat a pass as a proof.

The timing view computes Welch’s two-sample t statistic from raw observations. The source view parses Python with the repository’s AST scanner and reports patterns that may deserve review.

|t| < 2.5No difference detected at the configured screen
2.5 ≤ |t| ≤ 4.5Inconclusive; collect more controlled measurements
|t| > 4.5Timing signal detected; investigate
CPython does not guarantee constant-time integer or control-flow execution. Production cryptography should use vetted native implementations and dedicated side-channel tooling.
